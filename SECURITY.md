# Security Policy

## Reporting a vulnerability or a missed detection

If you find a dangerous skill pattern that skillvet does not catch, or a
vulnerability in skillvet itself, please open a GitHub issue with a minimal,
redacted example. For sensitive reports, contact the maintainers privately
through GitHub before filing publicly.

## Scope note

skillvet is a static, pattern-based first pass. A clean scan is not a
guarantee that a skill is safe. Always review skills that request broad
permissions, network access or credentials.
